# 📁 Final Conclusion

The investigation into **Operation Shadow Drop** successfully reconstructed the complete attack lifecycle through detailed analysis of the captured network traffic and attacker activities. The evidence shows that the attacker began by performing reconnaissance against the target web application, identifying accessible directories and resources before locating a vulnerable file upload location.

The attacker exploited the insecure upload functionality to deploy a malicious PHP web shell (`image.jpg.php`), which enabled remote command execution on the compromised server. Through this web shell, the attacker gained command-line access as the **www-data** service account and conducted post-exploitation reconnaissance using commands such as `whoami`, `uname -a`, `pwd`, `ls /home`, and `cat /etc/passwd` to gather information about the compromised host and its operating environment.

Network analysis also revealed continued communication over TCP port **8080**, indicating an interactive session between the attacker and the compromised server. This activity demonstrates that the attacker maintained remote control of the web shell while issuing commands and exchanging data. Additionally, the attempted access to sensitive system files such as `/etc/passwd` indicates an effort to obtain information that could support privilege escalation or further compromise.

Although the investigation did not reveal evidence of a successful large-scale data exfiltration, the compromise represented a significant security incident. The presence of an active web shell provided the attacker with persistent remote access and the ability to execute arbitrary commands, creating the potential for data theft, malware deployment, credential harvesting, lateral movement, or additional attacks if left undetected.

Overall, the investigation highlights the critical importance of securing file upload functionality, validating user-supplied content, implementing least-privilege access controls, continuously monitoring web server activity, and deploying effective detection mechanisms capable of identifying web shell activity and anomalous network communications. Applying the defensive recommendations and SOC improvements outlined in this report will significantly strengthen the organization's resilience against similar attacks and improve its ability to detect and respond to future security incidents.
