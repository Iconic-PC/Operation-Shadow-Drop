# 📁 Investigation Findings

### Overview

This section documents the key findings discovered during the analysis of the **Operation Shadow Drop** investigation.

The findings are based on the examination of captured network traffic, packet analysis, and investigation of suspicious activities observed within the provided evidence.

Each finding will document the evidence discovered, the analysis performed, and its relevance to understanding the attacker’s activities.

***

### Findings Covered

The investigation focuses on identifying:

#### Finding 1 — Attack Origin

Determining the source location and identifying information associated with the attacker’s connection.

#### Finding 2 — Attacker User-Agent

Analyzing HTTP request information to identify the tools or software used by the attacker.

#### Finding 3 — Malicious Web Shell

Identifying any malicious scripts or web shells introduced into the affected system.

#### Finding 4 — Upload Directory

Determining where malicious files were uploaded and stored within the target environment.

#### Finding 5 — Outbound Communication Port

Analyzing network communications to identify external connections established after compromise.

#### Finding 6 — Targeted Exfiltration File

Identifying sensitive files or information targeted during the attacker’s attempted data extraction.

***

### Investigation Method

The findings are developed through:

* PCAP file analysis using Wireshark.
* Examination of network requests and responses.
* Analysis of suspicious traffic patterns.
* Extraction of relevant indicators of compromise.
* Documentation of supporting evidence and screenshots.
