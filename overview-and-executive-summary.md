# 📄 Overview & Executive Summary

### Overview

**Operation Shadow Drop** is a SOC incident investigation conducted as part of the **INT401: Network Security Operations** course under the **Ethical Hacking and Digital Forensics Internship** program.

The investigation focuses on analyzing captured network traffic to identify malicious activity, understand attacker behavior, determine the techniques used during the intrusion, and document the evidence discovered during the analysis.

The investigation was performed through packet capture analysis, traffic examination, identification of suspicious communications, and reconstruction of the attack activities observed within the network environment.

***

### Executive Summary

This report documents the investigation of a simulated cyber incident involving unauthorized activity against a web application environment.

The analysis involved examining network traffic to identify indicators of compromise, trace attacker actions, and determine the methods used to compromise the affected system.

The investigation aims to identify:

* The origin of the attack.
* The tools and techniques used by the attacker.
* Malicious files or scripts introduced into the environment.
* Communication channels used after compromise.
* Potential attempts to access or extract sensitive information.

The findings from this investigation provide insight into the attack lifecycle and highlight security improvements required to strengthen detection, prevention, and incident response capabilities.

***

### Key Investigation Areas

The investigation focuses on:

* Network traffic and packet analysis.
* Attacker identification and activity tracking.
* Malicious file and web shell analysis.
* Attack timeline reconstruction.
* Impact assessment.
* Security recommendations.
